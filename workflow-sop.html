Workflow SOP: Demo Request Lead Nurture

Fyzer Co HubSpot Account · Prepared by C Okeniyi, RevOps Admin · October 2026
Overview
Purpose
Automatically enrol and nurture every contact who submits the Fyzer Co demo request form. The workflow assigns the contact to the correct lifecycle stage, sends a confirmation email, and creates a follow-up task for the sales owner — eliminating manual handoff lag and ensuring no lead falls through the cracks.
Enrolment trigger
Contact submits the Fyzer Co - Demo Request Form on any page of clementokeniyi.github.io
Workflow map
⚡
Trigger
Form submitted — Demo Request Form
Contact fills in the HubSpot form on contact.html. Enrolment fires immediately on submission.
1
Action
Set Lifecycle Stage → Marketing Qualified Lead
Updates the contact's Lifecycle Stage property from Lead → MQL to signal intent to the sales team.
2
Action
Send confirmation email — "We received your demo request"
Automated email sent immediately to the contact confirming receipt and setting expectations (response within 1 business day).
⏱
Delay
Wait 10 minutes
Buffer before creating the sales task — allows time for the contact record to fully sync and enrich.
3
Action
Create task for deal owner — "Follow up: demo request"
Creates a HubSpot task assigned to C Okeniyi with due date of next business day. Task note includes the contact's message field value.
?
Branch / If-Then
Is Company Size = 100+ employees?
Routes the lead to the appropriate follow-up track based on company size property.
✓ Yes — Enterprise
Set Lead Status → In Progress
Add to "Enterprise Prospects" list
Notify owner via Slack (if connected)
✗ No — SMB
Set Lead Status → New
Add to "SMB Prospects" list
Enrol in 3-email nurture sequence
⏱
Delay
Wait 3 business days
If no meeting booked and lead status has not changed to "Connected", send a follow-up email.
?
Branch / If-Then
Has a meeting been booked?
Checks if the contact has a Meeting activity logged in the last 3 days.
✓ Yes
Set Lifecycle Stage → Opportunity
End workflow — contact is being worked
✗ No
Send follow-up email: "Still interested in a demo?"
Wait 5 more days → if still no response, set Lead Status → Unqualified
✓
End
Workflow complete
Contact is either progressed to Opportunity or marked Unqualified for future re-engagement.
