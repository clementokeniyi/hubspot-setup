Integration SOP: HubSpot ↔ Salesforce

Fyzer Co HubSpot Account · Prepared by C Okeniyi, RevOps Admin · October 2026
Overview
Purpose
Establish a bi-directional sync between HubSpot (marketing & top-of-funnel CRM) and Salesforce (enterprise sales CRM) so that leads, contacts, companies, and deals flow seamlessly between both systems without manual data entry. HubSpot owns the marketing and MQL lifecycle; Salesforce owns the SQL-to-close lifecycle.

Setup steps
  • 1
    Install the HubSpot-Salesforce connector
    In HubSpot: Settings → Integrations → Connected apps → Search "Salesforce" → Install. Requires HubSpot Professional and Salesforce System Administrator credentials.
  • 2
    Authenticate with Salesforce
    Log in with Salesforce admin credentials when prompted. Grant HubSpot the required API permissions (read/write on Leads, Contacts, Accounts, Opportunities, Tasks).
  • 3
    Configure sync settings
    Choose sync direction per object. Set the "Include in sync" filter — recommend syncing only contacts with Lifecycle Stage = MQL or later to avoid flooding Salesforce with unqualified leads.
  • 4
    Map fields
    In the field mapping tab, map each HubSpot property to the corresponding Salesforce field. Pay special attention to custom fields — create matching custom fields in Salesforce before mapping.
  • 5
    Run initial sync & verify
    Trigger a manual sync for 5 test contacts. Verify records appear correctly in Salesforce. Check for duplicates, missing fields, or formatting errors. Document any discrepancies.
  • 6
    Set sync error monitoring
    Enable sync error notifications in HubSpot. Review the Sync errors log weekly (Settings → Integrations → Salesforce → Sync errors). Common errors: duplicate email, required field missing, field type mismatch.
