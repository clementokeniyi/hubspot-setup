Automation Troubleshooting SOP

Fyzer Co HubSpot Account · Prepared by C Okeniyi, RevOps Admin · October 2026
Scope
This SOP covers how to diagnose and resolve issues with HubSpot automations — including Workflows, Sequences, Forms, and Email sends. Follow this playbook before escalating to HubSpot support. Most automation failures fall into three root causes: enrolment criteria not met, missing contact properties, or timing/delay misconfigurations.

YES

NO

YES

Enable re-enrolment in workflow settings OR manually enrol the contact.
Still not enrolling

Common errors & fixes
ErrorRoot causeFix
Contact not enrolling in workflow Trigger criteria not met; workflow paused; contact previously unenrolled 1. Verify contact meets every AND condition in the trigger. 2. Check workflow is ON. 3. Enable re-enrolment if contact was enrolled before. 4. Check Workflow → History tab for unenrolment reason.
Email in workflow not sending Contact is unsubscribed; email is a draft; contact's email field is empty 1. Check contact's email subscription status. 2. Confirm the email inside the workflow is Published, not Draft. 3. Verify the contact record has a valid email address.
Branch logic taking wrong path Condition using "is equal to" instead of "contains"; property value has a typo; timing issue with property update 1. Review the branch condition. Use "contains" for text fields where values may vary. 2. Check the actual value on the contact record — it may differ from what the branch expects. 3. Add a 5-minute delay before the branch to allow upstream property updates to process.
Sequence email not sending Contact unenrolled manually; task not completed; contact replied (auto-unenrolled) 1. Open the contact record → Sequences tab. Confirm enrolment status. 2. If a task is in the sequence, check if it was marked complete. 3. Check if the contact replied — sequences auto-unenrol on reply. Re-enrol manually if needed.
Form not capturing submissions Form embed code is outdated; form is unpublished; GDPR field missing 1. Re-copy the embed code from HubSpot (Marketing → Forms → Share → Embed code). 2. Confirm the form is Published. 3. If using GDPR features, ensure the consent checkbox is included in the form.
Workflow updating wrong contacts Trigger is too broad; missing AND conditions; all contacts segment selected 1. Add additional AND conditions to narrow the trigger. 2. Test using "Test" mode or manually enrol one contact to verify behaviour. 3. Review the enrolled count in the Performance tab and pause if it looks incorrect.
Delay not working as expected Delay is set in working hours; timezone mismatch; delay skipped due to enrolment time 1. Check if the delay is "Wait X days" vs "Wait until time" — they behave differently. 2. Confirm the account timezone in Settings → Account → Time zone. 3. If using "Wait until a specific day/time", verify the day of enrolment vs the next occurrence of that time.
Where to find automation logs in HubSpot
Log locationWhat it showsHow to access
Workflow HistoryEvery contact enrolled, unenrolled, and step-by-step action log with timestampsAutomations → Workflows → [Workflow name] → History tab
Contact timelineAll automation events on a specific contact (enrolments, emails sent, tasks created)Contact record → Activity tab → Filter by "Workflow"
Email send logWho received the email, delivery status, open/click dataMarketing → Email → [Email name] → Performance tab → Recipients
Form submissionsAll form submissions with field values and contact created/updatedMarketing → Forms → [Form name] → Submissions tab
Sequence enrolment logWho is enrolled, which step they're on, unenrolment reasonCRM → Contacts → [Contact] → Sequences tab
When troubleshooting, always start with the contact record's Activity timeline — it shows the exact automation events in chronological order and is the fastest way to understand what happened and when.
