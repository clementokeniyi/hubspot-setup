User Permissions & Teams SOP

Fyzer Co HubSpot Account · Prepared by C Okeniyi, RevOps Admin · October 2026
Overview
This SOP defines how user access, roles, and team structures are configured in the Fyzer Co HubSpot account. The principle of least privilege applies — every user gets the minimum access required for their role. The RevOps Admin (C Okeniyi) owns all permissions configuration and reviews access quarterly.

User provisioning process
StepActionOwner
New hire requestHR submits access request to RevOps Admin with: name, email, role, team, start dateHR
Role assignmentRevOps Admin creates user in HubSpot (Settings → Users & Teams → Add user), assigns pre-built roleRevOps Admin
Team assignmentAssign user to the correct HubSpot team so deal and contact ownership filters work correctlyRevOps Admin
Seat typeAssign correct seat: Sales seat for reps, Marketing seat for marketers, Service seat for CSRevOps Admin
ConfirmationSend onboarding email with HubSpot login instructions and link to internal training docRevOps Admin
OffboardingOn last day: reassign all owned contacts/deals to manager, deactivate user (do not delete)RevOps Admin
In the current Fyzer Co free demo account, the account has a single user (C Okeniyi, Super Admin). This SOP documents the full user management framework to be implemented as the team grows. HubSpot free plan allows up to 2 users. Additional users and role-based permission sets require Professional plan.
